# Code of conduct

RAGX is built by students and volunteers. Everyone is welcome, whatever their experience level.

- **Be kind and assume good intent.** Beginners' questions are welcome; answer them the way you would have wanted to be answered.
- **Critique ideas, not people.** Review comments should explain *why* and suggest a way forward.
- **No harassment, discrimination, insults or personal attacks**, in any project space: issues, pull requests, discussions or chat.

Maintainers may edit or remove contributions and block participants who break these rules. Report problems privately to the maintainers, through the contact on the maintainer's GitHub profile. Reports are handled confidentially.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
